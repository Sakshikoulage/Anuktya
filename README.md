 Anuktya 

An online art marketplace where artists can showcase their artwork and customers can explore and commission custom pieces.

 Live Demo: https://anuktya-kdmoufmgq-sakshikoulages-projects.vercel.app/

Tech Stack:
- React
- JavaScript
- HTML & CSS
- Supabase

Features:
- Browse artwork
- Artist and buyer accounts
- Custom art commissions
- Commission order tracking
